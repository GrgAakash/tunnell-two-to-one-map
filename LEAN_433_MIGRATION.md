# Lean 4.33 compatibility trial

## Purpose

Palomar mechanically verified the Lean 4.28 submission at
`6c7a660788946203576c0600843525e99072c114`, but its status subsequently reported
that the Challenge renderability check would be retried. No rendering failure
diagnostic was available in the submission status.

This branch tests the workaround previously used in the
[Erdos migration](https://github.com/GrgAakash/factorial-hypergraph-auxiliary-erdos/commit/a8c3b644aee8626207b288b89964b28dce51ab31).
That precedent motivates a compatibility trial; it does not establish the
underlying cause of this submission's rendering problem.

## Pins

- Lean: `leanprover/lean4:v4.33.0`
- Mathlib: `db584cd6d46c92f209a44c0f1c829460d327499d`
- lean4export: `15f6055e299ad5b89345e533cc2192f4cc00f659`

The dependency manifest was regenerated by `lake update`. Comparator,
Landrun, and NanoDa retain their previous pins. NanoDa remains enabled for
both Comparator configurations.

## Scope

The toolchain, dependency lockfile, matching exporter, and associated notes
were updated. The first Linux build identified four proof compatibility
failures. Subsequent builds exposed further compatibility issues. The repairs
do not change any theorem statement, assumption,
executable definition, Challenge file, theorem selection, permitted-axiom
list, or manuscript:

- `PartialStableMatching.lean`: explicitly unfold `Blocks` when converting
  perfect stability to partial stability.
- `ParkingRearrangement.lean`: obtain the indexing equality directly from
  `List.get_ofFn`, then apply the existing index bound.
- `ResidualTargetTest.lean`: apply `directTargetUsed_iff` to an explicitly
  typed `ARep n` term, avoiding rewrite matching through the subtype.
- `MidpointBound.lean`: use the existing `DirectionKey.form_le_of_le` lemma
  instead of relying on simplification of the underlying lexicographic order.
- `OrderedGenerator.lean`: expose the integer-offset embedding application
  before `omega`; use explicit `List.getElem_map` equalities in the stream-order
  proof and a bounded, theorem-local heartbeat allowance of 800000. The latter
  changes elaboration resources, not the statement or the kernel checks.
